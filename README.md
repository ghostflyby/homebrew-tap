# Ghostflyby Tap

## How do I install these formulae?

`brew install ghostflyby/tap/<formula>`

Or `brew tap ghostflyby/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "ghostflyby/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
